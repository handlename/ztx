# Glossary

The terminology used throughout this manual is defined once, in the repository:

**[GLOSSARY.md](https://github.com/handlename/ztx/blob/main/GLOSSARY.md)**

It covers the terms that carry the design — *agent CLI*, *Terminal Thread*,
*PTY proxy*, *adapter*, *fallback quality*, *session log*, *scrollback*, *tap*,
*OSC title*, *title mode*, *prefix key*, *hint mode*, *export*, *IPC socket*,
*project socket*, and *alternate screen*.

The definitions are deliberately kept in one place instead of being copied here,
so that this manual and the repository can never drift apart on what a word
means.
