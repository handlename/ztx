# 設定

ztx は起動時に省略可能な設定ファイルを読み込みます。すべての設定は独立しています。キーが存在しない、値が認識されない、またはファイル自体が存在しない場合でも、その設定の組み込みデフォルト値にフォールバックします。設定ファイルが壊れていても ztx の起動がブロックされることはありません。

## ファイルの場所

```
~/.config/ztx/config.toml
```

ztx は `$XDG_CONFIG_HOME` を尊重します。変数が設定されていて空でない場合、パスは `$XDG_CONFIG_HOME/ztx/config.toml` になります。

## 優先順位

**CLI 引数 > `config.toml` > 組み込みデフォルト**

コマンドラインで渡されたフラグは常に優先されます。`config.toml` は明示的なフラグが指定されていない設定を補います。どちらのソースも値を提供しない場合、組み込みデフォルトが適用されます。

## エラー時の動作

| 状況 | 結果 |
|-----------|--------|
| ファイルが存在しない | すべての設定が組み込みデフォルトを使用します。起動は正常に続行されます。 |
| ファイルが読み取れない（パーミッション、I/O エラー） | すべての設定が組み込みデフォルトを使用します。起動は正常に続行されます。 |
| ファイルに不正な TOML が含まれる | すべての設定が組み込みデフォルトを使用します。ログ（`ZTX_LOG`）に警告が出力されます。 |
| 単一のキーに認識されない値がある（例：無効な `prefix` コード） | そのキーは組み込みデフォルトを使用します。他のキーは正常にパースされます。ログに警告が出力されます。 |

## キー

### `prefix`

ztx のキーバインドを有効にするプレフィックスキー。

| | |
|-|-|
| **型** | string |
| **デフォルト** | `"ctrl-]"` |
| **構文** | `ctrl-<key>` または `c-<key>`（大文字小文字不問） |

単一文字の Ctrl コードのみ受け付けられます。コードはキーの ASCII 値を下位 5 ビットでマスクしてエンコードされ、ターミナルの Ctrl シーケンスのエンコード方法に一致します。`ctrl-@`（ヌルバイト `0x00` にマップされる）は明示的に拒否されます。認識されない値は無視され、デフォルトが使用されます。

有効な例：`"ctrl-]"`、`"ctrl-a"`、`"Ctrl-A"`、`"C-]"`。

---

### `editor`

エクスポートおよびヒントモードでファイルを開く際に使用するエディターコマンド。

| | |
|-|-|
| **型** | string |
| **デフォルト** | _(なし；`$ZTX_EDITOR`、次に `zed`、次に `$EDITOR` にフォールスルー)_ |

値は空白で分割されてプログラムと引数になるため、`"zed --wait"` は有効です。空白のみの値は未指定として扱われます。解決順序の詳細については [環境変数](environment-variables.md) を参照してください。

---

### `[status_emoji]`

Claude Code アダプターのマネージドセッションタイトルに表示される絵文字プレフィックス。各キーは省略可能です。省略したキーはその状態の組み込みデフォルトが維持されます。

| キー | 型 | デフォルト | 説明 |
|-----|------|---------|-------------|
| `busy` | string | `"🔄"` | Claude がレスポンスを生成中です。 |
| `idle` | string | `"⏳"` | Claude が次のユーザーメッセージを待機中です。 |
| `waiting` | string | `"🔔"` | Claude がユーザーへの質問または選択肢の提示のために停止しています。 |

---

### `[notify]`

macOS デスクトップ通知の動作。Claude Code セッションが入力待ちになるか、レスポンスを完了したときに通知が発火します。`$PATH` 上に [`terminal-notifier`](https://github.com/julienXX/terminal-notifier) が必要です。存在しない場合は何も行いません。

| キー | 型 | デフォルト | 説明 |
|-----|------|---------|-------------|
| `desktop` | bool | `true` | デスクトップ通知を送出するかどうか。`false` に設定すると完全に無効化します。 |
| `sound` | string | `"Glass"` | システム設定 → サウンドに記載されている通知サウンド名。`""` に設定するとサイレント通知になります。 |

## 完全な例

```toml
# ~/.config/ztx/config.toml

# ztx のすべてのキーバインドに使用するプレフィックスキー（デフォルトは ctrl-]）。
prefix = "ctrl-]"

# エクスポート（ctrl-] e）とヒントモード（ctrl-] f）で開くエディター。
# 空白で分割されます。"zed --wait" は --wait を zed に渡します。
editor = "zed --wait"

[status_emoji]
# マネージドなターミナルスレッドタイトルの絵文字プレフィックス（Claude アダプター）。
busy    = "🔄"   # レスポンス生成中
idle    = "⏳"   # 次のメッセージ待機中
waiting = "🔔"   # 質問または選択肢プロンプトでブロック中

[notify]
# terminal-notifier 経由の macOS デスクトップ通知（brew install terminal-notifier）。
desktop = true    # false に設定すると無効化
sound   = "Glass" # サウンド設定からのサウンド名；"" でサイレント
```
