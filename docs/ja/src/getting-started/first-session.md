# 最初のセッション

このチュートリアルでは、ztx が何をするかを順を追って説明します。[ztx をインストール済み](installation.md)で、Claude Code (`claude`) が使える状態を前提とします。

## ステップ 1: ラップされたセッションを開始する

Zed のエージェントパネル内でも他の場所でも、ターミナルを開いて次のコマンドを実行してください:

```sh
ztx run -- claude
```

ztx は Claude Code を PTY proxy の中で起動します。出力は `claude` を直接実行した場合と見た目は変わりません。押したキーはすべて Claude に届き、Claude が書いた全バイトはそのままターミナルに返ってきます。ztx はデフォルトで透過的に動作します。

別のエージェントをラップするには、`claude` の部分をそのコマンドに置き換えてください。アダプター (adapter) はコマンド名から自動検出されます:

```sh
ztx run -- agy          # antigravity-cli
```

それ以外のもの（シェルやカスタムスクリプトなど）には `--adapter none` を渡してください:

```sh
ztx run --adapter none -- bash
```

ztx のキーバインドとエクスポート機能は引き続き動作します。アダプター固有のセッション名の補完のみが無効になります。

## ステップ 2: セッション名の変化を確認する

Zed の Terminal Thread 内で実行している場合、エージェントパネルのサイドバーでスレッド名を確認してください。Claude が「思考中」「返答待ち」「アイドル」といった状態を遷移するにつれて、ztx がステータス絵文字付きで名前を更新します
（`🔄` 処理中、`⏳` アイドル、`🔔` 入力待ち）。

名前自体はプロジェクトから取得されます。通常はカレントディレクトリから導出されたワークツリー名またはブランチ名です。詳細と設定オプションは [セッション名](../guide/session-names.md) を参照してください。

## ステップ 3: ログからファイルを開く

Claude が何らかの出力を生成したら、次のキーを押してください:

    ctrl-] f

画面上に見えているすべてのファイルパスにヒントラベルが表示されます。ラベル（1〜2 文字）を入力すると、対応するファイルが指定行の Zed で開きます。何も開かずに終了するには `Escape` を押してください。

Zed のビルトイン cmd+click も `path:line:col` のパターンを検出して直接開けます。その場合は ztx の操作は不要です。

ヒントモード (hint mode) とフォールバック動作の詳細は [ログからファイルを開く](../guide/open-files.md) を参照してください。

## ステップ 4: セッションログをエクスポートする

次のキーを押してください:

    ctrl-] e

ztx がセッションのトランスクリプトを Markdown に変換してエディタで開きます。Claude アダプターが Claude のネイティブトランスクリプトを見つけられる場合はそれが使われます（完全な再現度）。見つからない場合は、ztx の PTY キャプチャによるプライマリスクリーンへのフォールバックになります。

同じプロジェクト内の別のターミナルから `ztx export` を実行することで、そのディレクトリの最新セッションをエクスポートすることもできます。

詳細は [セッションログのエクスポート](../guide/export-log.md) を参照してください。
